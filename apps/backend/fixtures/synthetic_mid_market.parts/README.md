# Lumenvale fixture parts

Demo data added by individual features, merged into
`synthetic_mid_market.json` when a demo org loads it (see
`app/ingestion/demo_orgs.py:load_fixture`). One JSON file per feature,
applied in file-name order: objects merge key by key, lists are appended,
other values replace. All data is synthetic.

The base file is generated by `research/demo_fixture/build_synthetic_fixture.py`;
parts are hand-written or generated by the script named in their `_source` key.
